# Modelo Entidad-Relación — ScoutVision AI

## Descripción

En esta carpeta se encuentra el diseño inicial de la base de datos de ScoutVision AI, un sistema orientado al análisis del rendimiento futbolístico y la identificación de jugadores con potencial.

El modelo fue diseñado en Draw.io y contempla el registro de futbolistas, equipos, partidos, estadísticas deportivas, informes de scouting y evaluaciones mediante inteligencia artificial.

## Características del diseño

- 21 entidades relacionadas.
- Claves primarias (PK) y foráneas (FK).
- Relaciones con sus respectivas cardinalidades.
- Tablas intermedias para resolver relaciones muchos a muchos.
- Diseño orientado a PostgreSQL.
- Organización siguiendo criterios de normalización de bases de datos.

## Herramientas

- Draw.io (diagrams.net)
- PostgreSQL (base de datos prevista)
